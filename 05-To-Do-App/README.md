# To-Do App

The To-Do App is a simple web application that helps users manage their daily tasks efficiently. It was built using HTML, CSS, and JavaScript.

## Features

- Add new tasks to the list.
- Mark tasks as completed.
- Delete tasks when they are no longer needed.
- Real-time updates without refreshing the page.
- Clean and responsive user interface for desktop and mobile devices.

## Files

- `index.html` — The main HTML structure for the to-do list layout.
- `./assets/style.css` — Styles for layout, task items, and overall design.
- `./assets/script.js` — JavaScript logic to add, remove, and manage tasks dynamically.

- Event handling

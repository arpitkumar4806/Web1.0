# Simple Calculator

The Simple Calculator is a basic web application that allows users to perform standard arithmetic operations. It was built using HTML, CSS, and JavaScript.

## Features

- Enter two numbers and perform basic operations: addition, subtraction, multiplication, and division.
- Instant calculation and result display.
- Clean and user-friendly interface.
- Responsive design that works smoothly on both desktop and mobile devices.

## Files

- `index.html` — The main HTML structure for the calculator layout.
- `./assets/style.css` — Styles for layout, buttons, and overall design.
- `./assets/script.js` — JavaScript logic to handle user input and perform calculations.
